# Coffee Diary
Coffee Diary es una aplicación web diseñada para ayudar a los amantes del café a descubrir nuevas cafeterías, guardar sus favoritas y compartir recomendaciones con otros usuarios.

## 📖 Descripción
El objetivo del proyecto es ofrecer una plataforma donde los usuarios puedan registrar las cafeterías que visitan, organizar sus lugares favoritos y encontrar nuevas opciones según las recomendaciones de la comunidad.
Este proyecto fue desarrollado como iniciativa personal para fortalecer habilidades en desarrollo web y diseño de aplicaciones centradas en el usuario.

---

## Funcionalidades
- Registro e inicio de sesión de usuarios
- Lista de cafeterías favoritas (Wishlist)
- Publicación de reseñas y recomendaciones
- Blog con contenido relacionado con el mundo del café

---
